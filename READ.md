# Electric Vehicle Charge and Range Analysis

## Project Description
This project analyzes Electric Vehicle (EV) data using Tableau. It provides interactive visualizations to compare EV brands, driving range, efficiency, top speed, body style, and seating capacity.

## Tools Used
- Tableau Desktop
- MySQL
- SQL
- CSV Dataset
- GitHub

## Features
- Brand vs Driving Range
- Brand vs Top Speed
- Brand vs Efficiency
- Fast Charging Analysis
- Body Style Analysis
- Seating Capacity Analysis
- Interactive Dashboard
- Tableau Story
